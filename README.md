# oreMiner

oreMiner runs a single ComputerCraft: Tweaked mining turtle from a surface base through stairs, floor main shafts, and paired mining shafts. This repository contains the current V0.9 candidate; the controlled-world release checks in [the plan](MINER_PLAN.md) are still open.

For setup, commands, and recovery, read the [operator guide](docs/operator-guide.md). For a first in-world trial, use the [controlled gallery test](docs/home-test.md) and a backed-up world.

The authoritative feature and safety specification is [MINER_PLAN.md](MINER_PLAN.md). Current implementation status and remaining gates are in [docs/STATUS.md](docs/STATUS.md).
